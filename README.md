# Data-Journalism-Case-Study-Veri-Gazetecili-i-Vaka-al-mas-
I extracted the limited number of publicly available martyr figures using web scraping, preprocessed and visualized this data, and examined the correlation between various development indicators and the number of martyrs.
Sınırlı sayıda açıklanan şehit sayılarını web kazıma ile çekerek bu verileri ön işleyip anlamlı hale getirip görselleştirdim ve çeşitli gelişmişlik göstergeleri ile şehit sayıları arasındaki korelasyonu inceledim.
